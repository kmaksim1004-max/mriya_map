# Mriya Map — Інтерактивна супутникова карта Землі 🌍

Сучасний інтерактивний веб-додаток супутникової карти Землі у стилі Google Maps, який працює безпосередньо у браузері без потреби у складних збірках чи платних API-ключах.

---

## ✨ Основні можливості

### 1. 🛰️ Супутникова основа високої чіткості
- Базовий шар карти — високодеталізовані глобальні супутникові фотографії Землі з роздільною здатністю до окремих будівель (Esri World Imagery).
- Підтримка швидкого перегляду ландшафту, об'єктів інфраструктури, лісових масивів та рельєфу.
- Опційне ввімкнення підписів міст, кордонів, доріг та координатної сітки (Graticule).

### 2. ⬟ Малювання та вирізання супутникових територій
- Зручне малювання замкнених контурів будь-якої форми (клік по карті для встановлення вершин).
- **Зручне замикання контуру**:
  - Клік по першій (червоній) вершині контуру.
  - Подвійний клік у будь-якому місці карти (при наявності від 3 точок).
  - Натискання клавіші `Enter`.
  - Кнопка «Замкнути» на верхній панелі керування.
- **Автоматичне захоплення супутникового знімка**: програма автоматично вирізає фрагмент супутникової карти по створеному контуру.

### 3. 📋 Копіювання та перенесення фрагментів місцевості
- **Копіювання самої території (супутникового знімка)** всередині контуру (`Ctrl+C` або кнопка «Копіювати»).
- **Вставка у будь-яку точку карти** (`Ctrl+V` або кнопка «Вставити»): скопійований супутниковий фрагмент накладається на нову місцевість для порівняння масштабу, форми та ландшафту.
- **Трансформація території**:
  - Плавне перетягування фрагмента за центральний маркер `✥`.
  - Обертання (поворот від -180° до +180° з кроком або кнопками ±15°).
  - Масштабування (зміна розміру від 20% до 300%).
  - Регулювання прозорості (від 10% до 100%) для наочного порівняння з рельєфом підкладки.
  - Розрахунок точної площі (м², га, км²) та периметра.

### 4. 🔍 Пошук та геолокація
- Пошук населених пунктів, адрес або географічних об'єктів (через OSM Nominatim API).
- Пряме введення координат (наприклад `50.4501, 30.5234`).
- Кнопка «Моє місцезнаходження» за допомогою браузерного Geolocation API з колом точності.

### 5. 📏 Лінійка та інспектор точки
- Вимірювання відстаней між точками маршруту з розрахунком дистанції у реальному часі.
- Інспектор точки при кліку: назва місця, координати та кнопка швидкого копіювання.

## 🚀 Як запустити

### Варіант 1: Локально у браузері
Просто двічі клікніть на файл `index.html` або відкрийте його у будь-якому браузері (Chrome, Firefox, Safari, Edge). Жодних серверів чи встановлення бібліотек не потрібно!

### Варіант 2: Запуск через локальний веб-сервер
```bash
# Python
python3 -m http.server 8000

# Node.js
npx serve .
```
Після цього відкрийте `http://localhost:8000` у браузері.

### Варіант 3: Публікація на GitHub Pages (безкоштовно у 1 клік)
1. Відкрийте цей репозиторій на GitHub: [kmaksim1004-max/mriya_map](https://github.com/kmaksim1004-max/mriya_map).
2. Перейдіть у вкладку **Settings** ⚙️.
3. У лівому меню оберіть **Pages**.
4. У блоці **Build and deployment** встановіть:
   - **Source**: `Deploy from a branch`
   - **Branch**: `main` / folder: `/ (root)`
5. Натисніть **Save**.
За хвилину ваша карта буде доступна за адресою:
👉 `https://kmaksim1004-max.github.io/mriya_map/`

## 🛠️ Стек технологій
- **HTML5 Canvas & CSS3** (інтерфейс у стилі Google Maps, адаптивний для ПК та смартфонів).
- **Vanilla JavaScript (ES6+)** (без важких фреймворків).
- **Leaflet.js** — легка картографічна бібліотека.
- **Супутникові тайли**: Esri / ArcGIS World Imagery & Boundaries.
- **Геокодування**: OpenStreetMap Nominatim.

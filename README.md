# Mriya Map — Інтерактивна карта Землі 🌍

Сучасний інтерактивний веб-додаток карти Землі у стилі Google Maps, який працює безпосередньо у браузері без потреби у складних збірках чи платних API-ключах.

---

## ✨ Основні можливості

### 1. 🗺️ Різноманітні режими відображення (Шари)
- **Карта (Світла)** — сучасна детальна карта міст, вулиць та інфраструктури (CartoDB Voyager / OpenStreetMap).
- **Супутник (Satellite)** — високодеталізовані глобальні супутникові фотографії Землі з роздільною здатністю до окремих будівель (Esri World Imagery).
- **Гібрид (Hybrid)** — поєднання супутникових знімків з чіткими межами країн, назвами міст та автошляхами.
- **Рельєф / Топографія (Terrain)** — карта висот з ізогіпсами та тіньовим рельєфом гір і низовин (OpenTopoMap).
- **Нічна / Темна тема (Dark)** — стильна контрастна темна карта для комфортної роботи вночі (CartoDB Dark Matter).

### 2. 🔍 Розумний пошук та швидкі локації
- Пошук будь-яких населених пунктів, адрес або географічних об'єктів (через OSM Nominatim API).
- Пряме введення координат (наприклад `50.4501, 30.5234`).
- Швидкі кнопки переходу: Київ, Львів, Одеса, Гора Говерла, Париж, Токіо, Нью-Йорк.

### 3. 📍 Інспектор точки та зворотне геокодування
- Клікніть у будь-яку точку карти, щоб поставити маркер.
- Автоматичне визначення назви місця, країни та поштової адреси.
- Копіювання точних географічних координат в один клік.
- Кнопка «Поділитися місцем» копіює пряме посилання з збереженим масштабом та координатами.

### 4. 📏 Інструмент вимірювання відстаней (Лінійка)
- Увімкніть режим лінійки, клікайте по карті для створення точок маршруту.
- Точний розрахунок дистанції у реальному часі (у метрах або кілометрах).

### 5. 🎯 Геолокація
- Кнопка «Моє місцезнаходження» миттєво знаходить вашу позицію за допомогою браузерного Geolocation API з колом точності.

### 6. 🌐 Координатна сітка та статус-бар
- Опція ввімкнення координатної сітки (паралелі та меридіани).
- Нижній рядок стану з динамічним відображенням координат курсора та поточного рівня масштабування (Zoom).
- Підтримка повноекранного режиму (Fullscreen).

## 🚀 Як запустити

### Варіант 1: Локально у браузері
Просто двічі клікніть на файл `index.html` або відкрийте його у будь-якому браузері (Chrome, Firefox, Safari, Edge). Жодних серверів, Node.js чи встановлення бібліотек не потрібно!

### Варіант 2: Запуск через локальний веб-сервер
```bash
# Python
python3 -m http.server 8000

# Node.js
npx serve .
```
Після цього відкрийте `http://localhost:8000` у браузері.

### Варіант 3: Публікація на GitHub Pages (безкоштовно у 1 клік)
1. Відкрийте цей репозиторій на GitHub: [kmaksim1004-max/mriya_map](https://github.com/kmaksim1004-max/mriya_map).
2. Перейдіть у вкладку **Settings** ⚙️.
3. У лівому меню оберіть **Pages**.
4. У блоці **Build and deployment** встановіть:
   - **Source**: `Deploy from a branch`
   - **Branch**: `main` / folder: `/ (root)`
5. Натисніть **Save**.
За хвилину ваша карта буде опублікована за посиланням:
👉 `https://kmaksim1004-max.github.io/mriya_map/`

## 🛠️ Стек технологій
- **HTML5 & CSS3** (чистий, оптимізований інтерфейс з дизайном у стилі Google Maps).
- **Vanilla JavaScript (ES6+)** (без важких фреймворків).
- **Leaflet.js** — швидка та легка картографічна бібліотека.
- **Провайдери тайлів**:
  - CartoDB Voyager & Dark Matter
  - Esri / ArcGIS World Imagery & Boundaries
  - OpenTopoMap & OpenStreetMap contributors
- **Геокодування**: OpenStreetMap Nominatim
